System Design

End-to-End Architecture

A five-stage edge-computing pipeline running entirely on consumer smartphones

📷

Standby Mode

Camera feed initializes. Lightweight Euclidean heuristic scans for the Wake Gesture — no GPU load.

~0ms GPU
→
✋

Wake Gesture

Distance(Wrist, IndexTip) > 0.30 held for 2s triggers LSTM activation — preventing thermal throttling.

2s hold
→
🦴

MediaPipe Holistic

Extracts 543 spatiotemporal landmarks: 33 pose, 468 face, 21+21 hand nodes in 3D (x,y,z).

1662 features
→
🧠

LSTM Inference

30-frame context window with stride-5 sliding inference. Softmax over ISL vocabulary — 166ms window.

<200ms
→
🔮

AR Anchoring

Unity AR Foundation raycasts 2D MediaPipe viewport coords to 3D world depth vector beside the speaker.

30 FPS
🔬

MediaPipe Holistic

Multi-stage ROI pipeline with GPU delegation for real-time 543-point skeletal extraction on edge devices.

Google
📉

LSTM Network

3-layer recurrent network with forget/input/output gates preserving temporal gesture trajectory memory.

TensorFlow
📐

Coordinate Normalization

All joints translated to Nose-origin, scaled by shoulder distance for full translation + scale invariance.

NumPy
🌐

AR Foundation

Unity3D cross-platform AR layer — ARCore (Android) + ARKit (iOS) with depth-sensing raycasting.

Unity 2022 LTS
